## أول تجربة

أرسل `/start` للبوت. ثلاثة أسئلة فقط — **لا يسألك عن عدد**:

```
🌍 في أي دولة نبحث؟        →  الأردن
📍 وفي أي مدينة أو منطقة؟   →  عمان — الدوار السابع
🏪 ما هو النشاط؟           →  عيادات أسنان
```

ثم يبدأ البحث فوراً: يبحث في خرائط جوجل وفي جوجل نفسه وفي إنستغرام وفيسبوك،
يفتح موقع كل محل، يقرأ حساباته وبايو الإنستغرام، ويستدعي الـAI لكل واحد.

**لا تنتظر انتهاء البحث كله، ولا تنتظر بعد كل قرار.** النظام يجهّز عميلين قبل
أن يعرض الأول، ويواصل التحليل بينما أنت تقرّر. فبعد كل إرسال أو حذف يكون التالي
مكتوباً وجاهزاً من قبل. عدد الجاهزين خلف البطاقة يظهر عليها: `📚 جاهز خلفه: 3`.

ولا يعرض أكثر من واحد في المرة — المخزون خلف الكواليس، والشاشة تبقى بطاقة واحدة.

كل عميل يأتي في **بطاقتين**.

**البطاقة الأولى — من هو وما مشكلته:**

```
🎯 عميل محتمل
🏪 عيادة سمايل لطب الأسنان
🗂 Dentist
📍 عمان, الأردن
⭐ 4.2 (38)

📞 الهاتف: +962 7 9000 0000
🌐 الموقع: https://smile.jo
📸 إنستغرام: https://www.instagram.com/smiledental
👥 فيسبوك: https://www.facebook.com/smiledental
🗺 الموقع على خرائط جوجل

📝 البايو
عيادة أسنان · عمان · حجز بالاتصال

🔍 المشكلة التي رصدناها
لا يوجد نظام حجز على الموقع، الحجز بالاتصال فقط خلال الدوام

📌 الدليل
الموقع يعرض رقم هاتف فقط ولا يحتوي على أي زر حجز أو نموذج

💡 الخدمة المقترحة
نظام WhatsApp للشركات

🎯 زاوية الإقناع
المريض الذي يبحث ليلاً لا يستطيع الحجز فيذهب لعيادة أخرى

📊 ملاءمة 78/100 · أولوية 72 · لغة الرسالة: ar
```

**البطاقة الثانية — الرسالة والأزرار:**

```
✍️ الرسالة الجاهزة إلى عيادة سمايل لطب الأسنان
━━━━━━━━━━━━━━━━━━

مساء الخير دكتور، مريت على موقع عيادة سمايل...

━━━━━━━━━━━━━━━━━━
📱 سترسل إلى: +962790000000

     [ ✅ إرسال ]  [ ✏️ تعديل ]  [ 🗑 حذف ]
          [ ➡️ التالي بدون قرار ]
```

- **✅ إرسال** → في الوضع اليدوي تتحدّث البطاقة ويظهر زر يفتح واتساب والرسالة
  مكتوبة جاهزة. ترسلها ثم تضغط **«✅ أرسلتها»** فيسجّلها النظام ويتابع الرد.
  في وضع الإرسال الآلي تخرج الرسالة مباشرة دون أي خطوة إضافية.
  **ثم يظهر العميل التالي وحده.**
- **✏️ تعديل** → يسألك ماذا تريد أن تغيّر. اكتب مثلاً «خليها أقصر» أو «احكي
  باللهجة الأردنية» أو «ركّز على موضوع الحجز». يعيد كتابتها ويحدّث نفس البطاقة
  بنفس الأزرار. عدّل كما تشاء حتى ترضى. (التعديل لا يمضي للتالي — أنت ما زلت
  على هذا العميل.)
- **🗑 حذف** → لا يُرسل شيء، **ويظهر العميل التالي وحده.**
- **➡️ التالي بدون قرار** → يتخطّاه للسرعة دون أن يبتّ فيه. بطاقته تبقى في
  المحادثة وأزرارها تعمل متى رجعت إليها.

**واحد في كل مرة، بلا توقف.** بعد كل إرسال أو حذف أو تخطٍّ يظهر التالي تلقائياً،
ويستمر الأمر حتى ترسل `/start` من جديد — عندها يتوقف ويبدأ بحثاً جديداً.
`/next` يستدعي التالي يدوياً في أي وقت.

> إن انتهى الطابور رد عليك: «لا يوجد عملاء آخرون بانتظار موافقتك».

## `/settings` — بدل لوحة التحكم

يعرض لك الوضع الحالي وتحته أزرار:

| الزر | ماذا يفعل |
|---|---|
| 🟢/🔴 الإرسال الآلي | يشغّل أو يطفئ خروج الرسائل فعلياً |
| 📤 بدّل طريقة الإرسال | يدوي ← Evolution ← Cloud API ← يدوي |
| 🗺 مفتاح الخرائط | مفتاح Places API — يجلب المحلات من خرائط جوجل |
| 🔍 مفتاح البحث | مفتاح Custom Search API — يجوز يكون من مشروع Google ثانٍ. اتركه فارغاً ليستخدم مفتاح الخرائط |
| 🔎 معرّف محرك البحث | Search engine ID — يفعّل البحث في إنستغرام وفيسبوك وجوجل |
| 📊 الحد اليومي | أقصى عدد رسائل في اليوم |
| 🌐 رابط Evolution | عنوان الخادم |
| 📛 اسم Instance | اسم الـinstance |

كل تغيير يُحفظ فوراً وتتحدّث نفس الرسالة أمامك.

> عند التبديل إلى الوضع اليدوي يُطفأ الإرسال الآلي تلقائياً — لا معنى لتشغيله
> على قناة لا ترسل بنفسها.

## 🔎 تفعيل البحث في إنستغرام وفيسبوك وجوجل

بدون هذه الخطوة يبحث النظام في **خرائط جوجل وحدها**. ومعها يبحث في أربعة مصادر
معاً في كل عملية:

| المصدر | الاستعلام | لماذا |
|---|---|---|
| Google Places | عدة صياغات للنشاط والمنطقة | المحلات المسجّلة على الخرائط |
| إنستغرام | `site:instagram.com <النشاط> <المنطقة>` | محلات كثيرة لا وجود لها على الخرائط أصلاً |
| فيسبوك | `site:facebook.com <النشاط> <المنطقة>` | الصفحات التجارية القديمة |
| جوجل العام | `<النشاط> <المنطقة> whatsapp` | من ينشر رقم واتساب في صفحته أو دليله |

ثم تُدمج النتائج كلها، ويُسقط منها من هو محفوظ عندك سابقاً، ولا يبقى إلا من
أمكن استخراج رقم قابل للمراسلة له.

**لماذا لا نفتح إنستغرام مباشرة؟** جرّبناها فعلياً: صفحة إنستغرام تفتح (612KB،
بدون حاجز تسجيل دخول) لكنها **لا تحتوي على البايو ولا رابط الموقع** — إنستغرام
صار يحمّل بيانات الحساب من داخل المتصفح بتوكن مصادقة. وفيسبوك يرد `400`،
وDuckDuckGo يرد `202` (حاجز بوتات). لا طريق مباشر يعمل.

**الطريق الذي يعمل:** جوجل فهرس الحساب من قبل، **والبايو محفوظ في نص نتيجة
البحث نفسها**. فنسأل جوجل بدل أن نسأل إنستغرام — ونحصل على الرابط والبايو معاً
في استدعاء واحد.

للتفعيل (خمس دقائق، مرة واحدة):

**مفتاحان لا مفتاح واحد.** Places و Custom Search لا يشترط أن يكونا في نفس
مشروع Google Cloud، ومفتاح الخرائط غالباً مقيّد على Places وحده فيرفض البحث
بـ`403 ... are blocked`. لذلك للبحث مفتاحه المستقل:

1. [Google Cloud Console](https://console.cloud.google.com/apis/library/customsearch.googleapis.com)
   → **ENABLE** لتفعيل **Custom Search API**
2. نفس المشروع → **Credentials** → **+ Create credentials** → **API key**
3. على المفتاح الجديد: **Restrict key** → **Custom Search API** فقط → **SAVE**
4. التلجرام → `/settings` → **🔍 مفتاح البحث** → الصق المفتاح الجديد
5. [programmablesearchengine.google.com](https://programmablesearchengine.google.com/controlpanel/create)
   → الاسم أي شيء → **What to search?** = **Search the entire web** → **CREATE**
6. انسخ **Search engine ID** من لوحة تحكم المحرك
7. التلجرام → `/settings` → **🔎 معرّف محرك البحث** → الصقه

> إن كان مفتاح الخرائط نفسه غير مقيّد ومفعّل عليه Custom Search، تكفي الخطوات
> 5–7 واترك 🔍 مفتاح البحث فارغاً — النظام يستخدم مفتاح الخرائط تلقائياً.

بعدها يظهر في البطاقة:

```
📸 إنستغرام: https://www.instagram.com/somecafe
👥 فيسبوك: https://www.facebook.com/somecafe
🔗 رابط البايو: https://linktr.ee/somecafe
💬 واتساب بالبايو: +962790000000

📝 البايو
Specialty coffee · Amman · Order via WhatsApp
```

والـAI يقرأ البايو أيضاً، فيلاحظ أشياء مثل: «يبيع عبر إنستغرام فقط»، أو «رابط
البايو Linktree وليس موقعاً حقيقياً»، أو «الطلب عبر واتساب بدون نظام».

**الحصة:** 100 بحث يومياً مجاناً، ثم 5$ لكل 1000. كل بحث عن عملاء يستهلك 3
استدعاءات ثابتة (إنستغرام + فيسبوك + جوجل العام)، بالإضافة إلى استدعاء واحد لكل
محل لم نجد حساباته على موقعه.

## لاحقاً: الإرسال الآلي والرد على العملاء

هاتان الميزتان تحتاجان جسر واتساب — الشيء الوحيد الذي يتطلب اشتراكاً.

**1.** نصّب Evolution API (أو WAHA) على VPS — حوالي 5$ شهرياً. أنشئ instance
وامسح رمز QR برقم واتساب الذي ستستخدمه.

**2.** من التلجرام: `/settings` →
- 🌐 رابط Evolution → `https://evo.yourdomain.com`
- 📛 اسم Instance → اسم الـinstance
- 📤 بدّل طريقة الإرسال → حتى تصل إلى Evolution
- 🟢 شغّل الإرسال الآلي

**3.** في n8n أنشئ credential باسم `Evolution API key` من نوع **Custom Auth**:

```json
{ "headers": { "apikey": "مفتاح_Evolution" } }
```

واربطه بعقدة **Evolution Send** في `BX2 · WhatsApp Send`.
(هذه الخطوة الوحيدة التي تبقى خارج التلجرام — مفاتيح n8n لا تُضبط إلا من n8n.)

**4.** في إعدادات الـinstance وجّه الـwebhook إلى:

```
https://baigr115.app.n8n.cloud/webhook/bx2-whatsapp-inbound
```

الأحداث: `MESSAGES_UPSERT` — وفعّل **Webhook Base64** حتى تُفهم الرسائل الصوتية.

عندها: العميل يرد (نصاً أو صوتاً) → يُحوّل الصوت إلى نص → يقرأ مسؤول المبيعات AI
سجل المحادثة كاملاً ويرد بلغة العميل ولهجته → تصلك نسخة على تلجرام.

**التدخل اليدوي:** افتح واتساب على جوالك واكتب في المحادثة. النظام يرى أن
الرسالة `fromMe` ويُطفئ الرد الآلي في هذه المحادثة فوراً ويخبرك. من تلك اللحظة
أنت المسؤول عنها وحدك.

النظام يصمت ويطلب تدخلك تلقائياً إذا: كان العميل غاضباً، أو طلب مسؤولاً، أو طلب
عدم مراسلته، أو سأل شيئاً لا يعرفه.

## عندما لا يعمل شيء

| العرض | السبب |
|---|---|
| البوت لا يرد | تأكد أن `BX2 · Telegram Brain` مفعّل في n8n |
| «انتهى البحث» مع 0 عملاء | مفتاح Google منتهي، أو النشاط/المدينة بلا نتائج |
| «لم أجد عملاء جدد» | كلهم موجودون من بحث سابق — جرّب مدينة أو نشاطاً آخر |
| النتائج من الخرائط فقط | ينقص مفتاح البحث أو معرّف المحرك — بدونهما لا يعمل إلا Places |
| لا يظهر عميل بعد الإرسال | انتهى الطابور — `/start` لبحث جديد |
| البحث بدأ ولم يصل عميل | انتظر دقيقة، أو أرسل `/next` — التحليل يستغرق ~15 ثانية لكل عميل |
| كل الرسائل «الوضع اليدوي» | هذا صحيح ومقصود — غيّره من `/settings` |
| العملاء يردّون بلا رد آلي | webhook الـEvolution غير مضبوط، أو تدخّلت في المحادثة |
| الرسائل الصوتية لا تُفهم | Webhook Base64 غير مفعّل في Evolution |
| لا تظهر حسابات سوشال | لم تضبط مفتاح البحث أو معرّف المحرك، أو المحل فعلاً بلا حسابات |
| `403 ... are blocked` | مفتاح البحث مقيّد ولا يشمل Custom Search API |
| المحرك يرجع صفر نتائج | أنشأت المحرك بـ«Search specific sites» بدل **Search the entire web** |

للتشخيص: n8n → **Executions** → افتح آخر تنفيذ فاشل، العقدة الحمراء تخبرك بالسبب.
